Installation

PMP is distributed as a Rust binary. This guide walks you through the prerequisites and the two ways of installing it.

Prerequisites

Section titled “Prerequisites”

  • Rust 1.85 or newer — PMP uses edition 2024. rustup is the usual way to get Rust.

  • A C compiler — the embedded SQLite database (rusqlite) is built from source:

    OS Requirement
    Linux build-essential
    macOS Xcode Command Line Tools
    Windows Visual Studio Build Tools
